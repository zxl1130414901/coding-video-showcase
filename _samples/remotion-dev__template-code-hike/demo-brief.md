# template-code-hike 能力演示脚本（v2）

## 选型依据
这个模板的价值不是“把代码打成字幕”，而是**代码本身逐 token 变形**：CodeHike 把两份代码做 token 级 diff 后插值（位置、颜色、增删），再叠加类型提示与错误标注。因此演示用一个连续改代码的故事，而不是五段互不相关的示例。

## 三段演示（5 个代码步骤，每步 6 秒）
1. **0–10s｜给类型加字段：token 级过渡**
   第 1 步是基础 `User` 类型；第 2 步把 `location: string` 插入类型与对象字面量。新增 token 平滑落位，旧 token 让位，行内不跳版。
   证明点：代码增删是动画过渡，不是切图。
2. **10–20s｜跨行插入与整段改写**
   第 3 步让 `user.location` 出现在类型与对象里，行内 `// @errors: 2339` 注释跟随代码定位；第 4 步换成 `useCounter` 的首次改写。
   证明点：跨行插入不跳版，注释与代码同框；大段改写仍按 token 对齐。
3. **20–30s｜重写并复用**
   第 5 步补上 `step` 参数与 `<App>` 调用，大段结构增删仍然按 token 对齐过渡。
   证明点：跨行、跨区块的重构也能做连续过渡。

## 渲染方式
`node node_modules/@remotion/cli/remotion-cli.js render src/index.ts Main`，5 步 × 180 帧 = 900 帧 / 30s / 1920×1080，`--concurrency=1`；poster.py 烧入中文标注。
